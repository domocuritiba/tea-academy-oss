# 🫖 Tea 101 — Introdução ao Tea Protocol

## 🌐 O que é o Tea Protocol?

O Tea Protocol é uma infraestrutura descentralizada que recompensa projetos de software livre (OSS) com base em sua reputação técnica. Ele permite que desenvolvedores, mantenedores e contribuidores sejam reconhecidos e recompensados por seu impacto real na comunidade open-source.

## 🎯 Objetivos do Tea Protocol

- Medir reputação técnica de projetos OSS
- Recompensar contribuições com tokens TEA
- Permitir staking em projetos promissores
- Criar um ecossistema sustentável para software livre

## 🧠 Conceitos-chave

| Termo | Definição |
|------|-----------|
| **teaRank** | Métrica de reputação técnica de um projeto |
| **Proof of Contribution** | Algoritmo que valida impacto real de contribuições |
| **Staking** | Apostar tokens TEA em projetos para apoiar e ganhar recompensas |
| **Brew.Fun** | Plataforma para criar ativos digitais ligados a projetos OSS |
| **Velodrome** | Infraestrutura de liquidez para ativos gerados no Tea |

## 🛠️ Como começar

1. Crie uma conta no [app.tea.xyz](https://app.tea.xyz)
2. Conecte sua carteira Ethereum (Sepolia testnet)
3. Vincule seu GitHub
4. Registre um projeto OSS ou faça staking em projetos existentes
5. Acompanhe sua reputação e recompensas

## 🧪 Testnet Sepolia

Durante a fase de testes, você pode experimentar o protocolo usando tokens TEA de testnet. Isso permite aprender e interagir sem custos reais.
